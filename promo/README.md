# easyApply Instagram Reel

- `easyApply-reel.mp4`: 24 seconds, 1080 × 1920, 30 fps, H.264 video with AAC audio.
- `cover.jpg`: matching cover image.
- `instagram-caption.txt`: suggested post caption.
- `render.py`: reproducible animation and original synthesized instrumental soundtrack.

The video uses illustrative interface graphics and fictional details, not a live screen recording. It has on-screen text and music, without voiceover. No stock music or external media were used. The logo is the project's existing asset.

Upload the MP4 as a Reel, choose the cover, and paste or adapt the caption. No public installation URL is included because one has not been provided.

To render again, run `render.py` using Python with Pillow and NumPy installed and FFmpeg available on PATH.
